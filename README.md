## Overview
The idea is to use color masks to guide the model in colorizing grayscale images. With this approach, the model can learn to select appropriate colors based on real image attributes such as object appearance, season, and lighting conditions. The color masks for training data are generated by dividing each image into `n_cell × n_cell` grids and computing representative color values—such as the mean or median—for each cell. By selecting color masks, the model can produce various colorized images from one grayscale input.

## Data Preparation
1. I used OpenCV for data preparation. Each image was resized so that its shorter edge became 96px, and cropped out in the center.
2. All images are converted into L\*a\*b color space. Every pixel values are standardized into 0 and 1.
3. Each image's color mask is generated by dividing image into `n_cell × n_cell` grids and computing median of each grid.

## Test Results
![test result](./CNN-model/test-results/11.png) \
The results demonstrate the model’s ability to recognize skies and assign blue tones. The model can also generate green colors for grass and trees to some extent. However, it still struggles to accurately colorize complex man-made objects. The frequent alternation between green and yellow shades in natural elements further suggests the difficulty of distinguishing between the two. 

![result](./CNN-model/appiled-color-masks.png) \
When experimenting with custom color masks derived from real masks by randomly shifting color values, the model produced different colorized outputs. This suggests that the model relies not only on the structural information from grayscale inputs but also on the color representations in the color masks. Although the generated outputs did not perfectly match the intended masks, the model's performance could be improved through data augmentation by creating multiple possible color targets from a single grayscale image. \
Please be aware that these experiments were conducted only with the Generator model, and no experiments with a GAN architecture have been performed yet.
